WHAT'S INCLUDED

Four areas we check and secure.

  1. 01

    Network security

    Firewalls, access control lists, VLANs and VPNs, set up so only the right people and devices get in.

  2. 02

    Ethical hacking

    With your written permission, we test your website and systems for weaknesses like SQL injection and XSS before someone else finds them.

  3. 03

    System hardening

    Updates, secure configuration and fewer open doors on your servers, routers and computers.

  4. 04

    Monitoring

    Dashboards and alerts with Prometheus and Grafana, so you notice problems early.

HOW IT WORKS

  1. 01 · SCOPE

  2. 02 · ASSESS

    Assess

    Scans, manual testing and a review of your configuration.

  3. 03 · REPORT

    Report

    A clear report in plain language, sorted by risk.

  4. 04 · HARDEN

    Harden

    We help fix the issues, then check them again.
